# Tajik Migration News RSS

Публичная RSS-лента с проверенными миграционными новостями, имеющими практическое значение прежде всего для граждан Республики Таджикистан, а также при необходимости для граждан стран Центральной Азии.

## Публичный RSS

`https://komronfarrukh.github.io/tajik-migration-news/feed.xml`

## Что находится в репозитории

- `feed.xml` — публичная RSS 2.0 лента.
- `config.json` — редакционные, языковые, тематические и безопасностные правила.
- `update_feed.py` — только валидатор RSS. Он **не ищет и не публикует новости самостоятельно**.
- `README.md` — описание проекта.

## Как теперь обновляется лента

Основное обновление выполняется почасовой автоматизацией ChatGPT.

Логика каждого запуска:

1. Проверить новые материалы за последний час.
2. Отдать приоритет официальным источникам: государственным органам, миграционным ведомствам, министерствам, посольствам и консульствам.
3. Для правовых изменений проверить первичный официальный источник.
4. Оценить практическую значимость для граждан Республики Таджикистан и, при необходимости, для граждан Центральной Азии.
5. Исключить дубликаты, сомнительные и конфликтные материалы.
6. Отредактировать материал на литературном таджикском языке по правилам `config.json`.
7. При наличии подходящего изображения использовать не более одного релевантного фото из надежного, предпочтительно официального источника.
8. Добавить материал в `feed.xml` только после проверки.

Если достойной новой новости нет, `feed.xml` не изменяется.

## Редакционный принцип

Лента является информационной, практической и законопослушной.

Основной фокус:

- законные интересы и безопасность граждан Республики Таджикистан;
- правила въезда, пребывания, регистрации и трудовой деятельности;
- законные возможности работы и учебы;
- консульская помощь;
- официальные изменения законодательства;
- защита прав исключительно законными средствами;
- полезные региональные изменения, относящиеся к гражданам Центральной Азии.

Материалы не должны противопоставлять государства, народы, организации или отдельных лиц. Не используются конфликтные, провокационные, оскорбительные, обвинительные или политически агитационные формулировки. О конкретных лицах и организациях публикуются только проверенные факты, необходимые для информационной цели новости.

Любые практические рекомендации должны быть направлены на соблюдение закона, правильное оформление документов и обращение в компетентные государственные органы, посольства и консульства.

## Забони таҳрир

Забони асосии лента — тоҷикӣ (`tg`).

Меъёри асосӣ:

- забони адабӣ, табиӣ ва фаҳмои тоҷикӣ;
- услуби забонӣ бо такя ба меъёрҳои матнҳои расмии Ҷумҳурии Тоҷикистон;
- шакли кӯтоҳи хабарӣ аз 2–3 сархат;
- сархати аввал бо `⚡️` оғоз мешавад;
- далели асосӣ дар сархати аввал оварда шуда, манбаъ баъд аз тире нишон дода мешавад;
- санаҳо бо сол навишта мешаванд: `1-уми сентябри соли 2026`;
- номҳои расмии давлатҳо истифода мешаванд: `Федератсияи Россия`, `Ҷумҳурии Қазоқистон`, `Ҷумҳурии Корея` ва ғайра;
- тарҷумаи калима ба калима ва қолабҳои сунъӣ истифода намешаванд.

## Тасвирҳо

RSS фазои номии Media RSS-ро дастгирӣ мекунад. Барои ҳар хабар ҳадди аксар як тасвири релевантӣ иҷозат дода мешавад.

Афзалият:

1. тасвир аз манбаи расмии худи хабар;
2. тасвири пресс-хидмат ё мақомоти давлатӣ;
3. тасвири мустақиман вобаста ба воқеа аз манбаи боэътимод.

Агар тасвири муносиб мавҷуд набошад, хабар бе тасвир нашр мешавад.

## `update_feed.py`

Скрипт танҳо сохтори `config.json` ва `feed.xml`-ро месанҷад: XML, RSS 2.0, майдонҳои ҳатмӣ, такрори пайвандҳо ва GUID, шумораи тасвирҳо ва дурустии URL-ҳо.

Он ягон хабарро аз Google News ё дигар манбаъҳо ҷамъоварӣ намекунад ва `feed.xml`-ро тағйир намедиҳад. Ин барои пешгирии нашри худкори матни хом ё санҷиданашуда пешбинӣ шудааст.

## GitHub Pages

Лента тавассути GitHub Pages дастрас аст. Барои ин репозиторий бояд дар **Settings → Pages** аз веткаи `main` ва папкаи `/ (root)` нашр шавад.
