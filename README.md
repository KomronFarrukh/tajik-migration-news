# Tajik Migration News RSS

Готовая заготовка агрегатора новостей для граждан Таджикистана, работающих или планирующих работать за рубежом.

## Что внутри

- `feed.xml` — готовая RSS 2.0 лента с начальными проверенными материалами.
- `config.json` — страны, темы и поисковые запросы.
- `update_feed.py` — автоматический сбор новых публикаций через Google News RSS, фильтрация и удаление дублей.
- `.github/workflows/update-feed.yml` — обновление ленты каждые 3 часа через GitHub Actions.

## Основные направления

Россия, Казахстан, Южная Корея, ОАЭ, Катар, Великобритания и Германия.

## Как получить постоянный RSS-адрес

1. Создайте публичный репозиторий GitHub, например `tajik-migration-rss`.
2. Загрузите в него все файлы из этого проекта.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. После публикации адрес будет примерно таким:

   `https://USERNAME.github.io/tajik-migration-rss/feed.xml`

Этот URL можно добавить в Feedly, Inoreader, Telegram RSS-боты и другие RSS-клиенты.

## Как работает автообновление

GitHub Actions запускает `update_feed.py` каждые 3 часа. Скрипт:
- выполняет тематические поиски;
- оставляет публикации, связанные с миграцией и работой;
- присваивает страну и тему;
- удаляет дубликаты;
- сохраняет до 120 последних материалов;
- обновляет `feed.xml`.

## Редакционная политика

Для важных юридических изменений желательно отдавать приоритет:
1. государственным и консульским источникам;
2. миграционным ведомствам;
3. крупным проверенным СМИ;
4. специализированным ресурсам только как дополнительным источникам.

Перед практическими действиями по вопросам въезда, депортации, разрешения на работу и регистрации всегда сверяйте новость с первичным официальным источником.
